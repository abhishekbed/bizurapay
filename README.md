# BizuraPay - B2B Payment powered by zkp and PYUSD

Seamless, verified B2B payments powered by zero-knowledge proofs and Stablecoins.  
Built at **ETHGlobal New Delhi 2025** 🚀

---

## 🌐 Overview

Business-to-business (B2B) payments today are **slow, expensive, and trust-heavy**.  
Merchants must repeatedly expose sensitive data to prove legitimacy, and cross-border payments involve long settlement times and high fees.

**ZK-BizPay** solves this by combining:

- **Zero-Knowledge Proofs (ZKPs)** for private, trustless business verification
- **Onchain Verified Merchant Registry** for transparent discovery
- **Stablecoin settlement (PYUSD)** for instant, borderless payments
- **B2B-specific flows** tailored for merchants and enterprises

---

## ❌ Problems in Current B2B Payments

1. **Trust & Verification** – Businesses cannot easily prove legitimacy without exposing sensitive data.
2. **Slow & Costly Transactions** – Traditional rails add delays, intermediaries, and high cross-border fees.
3. **Currency Friction & Volatility** – Cross-border trades face conversion costs and unstable settlement.

---

## ✅ Our Solution

1. **Zero-Knowledge Proofs**  
   Businesses prove compliance without revealing private data.
2. **B2B Payments Onchain**  
   Fast, programmable, trustless settlement between merchants.
3. **Stablecoin Settlement**  
   Instant transfers in PYUSD and USDC with minimal fees.
4. **Verified Merchant Registry**  
   Public onchain list of trusted businesses to build confidence.

---

## 🔄 How It Works

1. **Merchant Registration**  
   Merchant submits details (name, reg #, tax ID, wallet, etc.).
2. **Verification**  
   Verifier validates offchain and issues a zk-proof (future: fully onchain).
3. **Onchain Listing**  
   Verified merchants appear in the onchain registry.
4. **Payments**  
   Other users/merchants pay them directly in PYUSD (future: multi-token support).

## ⚡ Getting Started

### Prerequisites

- **Node.js** v20+
- **npm** or **yarn**
- MetaMask or compatible Ethereum wallet
- Deployed contracts (update addresses in `PayPalUSD.jsx` and `abi.json`)

### Branching Strategy

- **main** → Stable production-ready code.
- **develop** → Active development branch. Check latest commits and new features here before merging to `main`.

To view commits on `develop`:

```bash
git checkout develop
git log --oneline
```

### Install

```bash
cd frontend
npm install
```

### Run Frontend

```bash
npm run dev
```

Visit `http://localhost:5173` (or your Vite dev port).
